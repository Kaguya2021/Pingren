# 🚀 Render Ping Bot (Nim)

Многопользовательский Telegram-бот для поддержания активности и мониторинга бесплатный сервисов на Render (или любых других HTTP-сервисов).

---

## 📱 Установка и запуск на Termux (Android)

### 1. Подготовка окружения
Откройте Termux и выполните команды:
```bash
pkg update && pkg upgrade -y
pkg install nim git sqlite openssl -y
